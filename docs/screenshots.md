# Real screenshot checklist

No screenshots have been fabricated. Capture these on a local browser after starting the app:

1. Document Management: show successful uploads, duplicates and indexed page/chunk counts.
2. AI Chat: one Arabic question, RTL answer, page citations and an expanded source passage.
3. Retrieval Comparison: show dense/BM25/hybrid/cross-encoder runs on the same question.
4. Evaluation: show metric/latency charts with dataset size and model configuration visible.

Save only screenshots of synthetic/public documents that you have permission to share in
`docs/screenshots/`. Add README image links after actual capture. Do not include personal
research notes, local filesystem secrets, or misleading model-performance labels.
